# Analisis Kesalahan Model Terbaik (`rf`) — Bagian Orang A

Analisis 7 sampel pertama False Positive (`reports/rf_fp.csv`, indeks `0`–`6`) dan 7 sampel pertama False Negative (`reports/rf_fn.csv`, indeks `0`–`6`) pada model Random Forest (`rf`, F1 = `0.9557`).

## Tabel Analisis (Bagian A: 7 FP + 7 FN)

| id | jenis (FP/FN) | cuplikan permintaan | kategori penyebab | dugaan kenapa model keliru |
|---|---|---|---|---|
| FP-01 | FP | `POST .../anadir.jsp ... id=2&nombre=Vino Rioja&precio=39&cantidad=4&B1=Aadir al carrito` | Karakter non-ASCII / pola parameter keranjang | Karakter aksen Spanyol yang ter-encode (`Añadir`) menghasilkan n-gram langka, ditambah parameter angka `precio`/`cantidad` yang sering mirip sampel serangan manipulasi harga. |
| FP-02 | FP | `POST .../pagar.jsp ... modo=insertar&precio=5353&B1=Confirmar` | Kemiripan n-gram kata kunci & nilai numerik | Kata `insertar` mengandung n-gram karakter `inse`/`nser`/`sert` yang tumpang tindih dengan kata kunci SQL `insert`, ditambah permintaan `POST` pendek dengan `precio=5353`. |
| FP-03 | FP | `GET .../editar.jsp?...&direccion=Calle Doctor Jose Manuel Pascual y Pascual 146, 4?C&ciudad=Banyeres del Peneds&...` | Tanda baca/non-ASCII pada nama & alamat | Alamat panjang memuat tanda `?` (`4?C`) dan karakter aksen (`Penedès`) yang memicu bobot anomali TF-IDF n-gram serta jumlah digit tinggi (`dni`, `cp`, `ntc`). |
| FP-04 | FP | `POST .../editar.jsp ... password=m9ncilla57&nombre=Delujan&apellidos=Anaya Pez&...` | Karakter non-ASCII & form panjang banyak digit | Nama beraksen (`Páez`) dan password campuran angka-huruf (`m9ncilla57`) dalam form panjang berdigit banyak menaikkan skor fitur khusus/digit dan n-gram langka. |
| FP-05 | FP | `POST .../anadir.jsp ... id=3&nombre=Vino Rioja&precio=39&cantidad=5&B1=Aadir al carrito` | Karakter non-ASCII / pola parameter keranjang | Pola hampir identik dengan FP-01; kombinasi `POST` pendek, karakter aksen `Añadir`, serta nilai `precio`/`cantidad` terlalu dekat dengan data serangan keranjang. |
| FP-06 | FP | `GET .../pagar.jsp?modo=insertar&precio=5518&B1=Pasar por caja` | Kemiripan n-gram kata kunci & nilai numerik | Sama seperti FP-02, potongan n-gram dari `modo=insertar` dan angka harga besar (`5518`) membuat pohon keputusan `rf` mengira ada parameter tampering / SQLi. |
| FP-07 | FP | `GET .../vaciar.jsp?B2=Vaciar carrito HTTP/1.1` | Permintaan sangat pendek & endpoint jarang | Permintaan `GET` sangat pendek tanpa parameter query lain sehingga nilai fitur panjang kecil dan n-gram `vaciar.jsp` jarang muncul pada data normal dominan. |
| FN-01 | FN | `PUT .../autenticar.jsp ... modo=entrar&login=dion&pwd=trictomo&remember=off&B1=Entrar` | Manipulasi metode HTTP (`PUT`) | Serangan hanya terletak pada metode `PUT` yang tidak wajar untuk login, sedangkan seluruh body tampak normal dan tidak memuat kata kunci SQL/XSS maupun karakter khusus. |
| FN-02 | FN | `POST .../registro.jsp ... password=dEsbR/'oce&...&ciudad=Jvea/Xbia&...` | Serangan disamarkan dalam form panjang | Payload sisipan singkat (`/'` di `password`) tenggelam oleh puluhan token n-gram form registrasi yang normal, dan hanya memicu 1 karakter kutip pada `n_karakter_khusus`. |
| FN-03 | FN | `POST .../pagar.jsp ... modo=insertar&precio=6499+&B1=Pasar por caja` | Karakter sisipan tunggal di parameter numerik | Anomali berupa tambahan spasi/`+` di belakang angka (`precio=6499 `) tidak dihitung sebagai karakter khusus dan struktur teksnya identik dengan `pagar.jsp` normal. |
| FN-04 | FN | `POST .../editar.jsp ... login=amm*a*mari&password=ch07ico3o&...` | Karakter sisipan tunggal (`*`) di form panjang | Karakter `*` pada `login=amm*a*mari` tidak termasuk daftar `n_karakter_khusus` (`' " < > ; ( ) % = -`), tidak memicu regex SQL/XSS, dan tertutup oleh panjangnya form normal. |
| FN-05 | FN | `GET .../editar.jsp?...&cp=09441&provincia=+&ntc=2965845845269028&B1=Registrar` | Anomali nilai parameter halus (nilai kosong) | Nilai `provincia=+` (setelah decode menjadi spasi kosong) adalah anomali parameter tanpa simbol serangan apa pun sehingga profil fiturnya identik dengan `GET` registrasi normal. |
| FN-06 | FN | `POST .../editar.jsp ... email=mallalie@u@logiteclin@es.@ly&...` | Anomali format parameter halus (`@` ganda) | Serangan berupa format email cacat dengan empat `@`, namun `@` tidak dihitung di fitur khusus dan struktur form lainnya identik dengan data edit profil normal. |
| FN-07 | FN | `GET .../autenticar.jsp?modo=entrar&login=?denise&pwd=pLaSMaDoR&remember=on&B1=Entrar` | Karakter sisipan tunggal (`?`) di nilai parameter | Simbol `?` pada `login=?denise` tidak dihitung di `n_karakter_khusus` dan sudah umum muncul sebagai pemisah query string `GET`, sehingga model gagal membedakannya dari login normal. |
